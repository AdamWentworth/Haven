# Security policy

## Reporting a vulnerability

Do not place exploit details, credentials, personal observations, or private infrastructure information in a public issue. Use GitHub private vulnerability reporting once the repository is published.

## Supported versions

HAVEN is pre-release software. Only the latest revision of the default branch will receive security fixes until a versioned release policy is established.

## Scope

Security reports may cover the local API, collectors, agent/hub protocol, authorization boundaries, secret handling, update process, dependency chain, or unintended collection and disclosure of personal information.
